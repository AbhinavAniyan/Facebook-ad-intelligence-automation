# Facebook Ad Intelligence Automation

AI-powered Facebook Ad analysis workflow built using **n8n, Apify, and Google Gemini**.

## Key Features
- Facebook Ad Library data extraction
- AI-powered video and text analysis
- Hook, ad copy, and CTA identification
- Ad creative comparison and ranking
- Automated PDF report generation

## Tech Stack
- n8n
- Apify
- Google Gemini
- Gotenberg

## Project Files
- `MySivi Ai Facebook Ad Intelligence.json` – n8n workflow
- `MySiviAI Report.pdf` – Analysis report
