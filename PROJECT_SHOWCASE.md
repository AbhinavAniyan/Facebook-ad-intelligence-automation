# Project Showcase – Facebook Ad Intelligence Automation

## Overview
An AI-powered workflow developed to automate Facebook Ad Library data extraction and creative analysis.

## Workflow Architecture

![n8n Workflow](screenshots/workflow.png)

## Technologies Used
- n8n – Workflow automation
- Apify – Ad data extraction
- Google Gemini – AI text and video analysis
- Gotenberg – PDF generation

## Key Capabilities
- Extract Facebook ad data
- Analyze video and text creatives
- Identify hooks, ad copy, and CTAs
- Compare and rank ad creatives
- Generate automated PDF reports

## Deliverables
- n8n workflow JSON
- AI-generated PDF analysis report
- Workflow architecture screenshot
